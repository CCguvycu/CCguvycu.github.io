// the terminal

A real shell. On your phone.

The app connects over a secure WebSocket and renders output through xterm.js — full colour support, interactive programs, window resize. The Linux environment lives entirely on the server.

⚡

Zero Storage

185 KB APK. No Linux environment on the phone — it all runs remotely on the server.

🖥

Real Terminal

Full xterm.js emulation — colours, cursor keys, tab completion, window resize, interactive programs.

📜

Command History

Every command logged per session to PostgreSQL. Browse and re-run from the history panel.

🔒

Token Auth

Your server, your token. No accounts, no cloud login, no third-party data sharing.

// REST API

API-first architecture.

The WebSocket server never touches the database directly. Everything goes through a FastAPI REST layer with JWT authentication, auto-generated Swagger docs, and paginated endpoints for sessions, commands, and alerts.

Python · FastAPI● live on Railway

    # paginated, filterable, JWT-protected
    return { "sessions": [...], "pagination": {...} }
🔐

JWT / OAuth2

Every endpoint validates a signed JWT. The server auto-refreshes tokens on 401 without dropping the session.

📄

Auto Swagger Docs

FastAPI generates live interactive docs at /docs. Every endpoint is documented and testable in-browser.

🔗

Internal Endpoints

Private /internal routes let the WebSocket server write sessions and commands without direct DB access.

// admin dashboard

Watch and control every session.

The web dashboard connects to the live API. As admin you can see every session, watch what anyone is typing in real time, and kill a connection instantly — from any browser, no app needed.

👁

Live View

Watch any active session in real time inside the browser. Read-only — the user never knows.

■

Kill Sessions

One click drops the connection. The WebSocket closes server-side and the terminal exits instantly.

⚠

Keyword Alerts

Dangerous commands like rm -rf or nc -e trigger instant alerts logged to the database.

🛡

HMAC Cookie Auth

Dashboard login uses HMAC-signed session cookies with 7-day expiry and per-IP rate limiting.

📡

IP Logging

Every connection logs the real client IP via X-Forwarded-For, stored per session in PostgreSQL.

🔄

Auto Deploy

GitHub Actions triggers a Railway deploy on every push to master. Zero-downtime continuous deployment.
