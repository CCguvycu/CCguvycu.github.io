Everything you need

⚡

Zero Storage

The Linux environment lives on your server. The app is just a window into it — 185 KB total.

🖥

Real Terminal

Full xterm.js emulation — colours, cursor keys, tab completion, window resize, interactive programs.

📜

Command History

Every command logged per session. Tap the history button to browse and re-run past commands.

🔒

Token Auth

Your server, your token. No accounts, no cloud login, no data shared with anyone.

👁

Live View

The web dashboard lets you watch any active session in real time from a browser.

⚠

Keyword Alerts

Dangerous commands trigger instant alerts on the dashboard so nothing slips by unnoticed.

// getting started

Up and running in 3 steps

01

Download the APK

Tap the download button above. When prompted, allow installs from unknown sources in Settings → Security.

02

Enter your server

On the connect screen, enter your server URL and token.
Default: wss://kali-terminal-production.up.railway.app

03

Connect

Tap Connect. You now have a full Linux shell on your phone. Run any command you like.

Ready to connect?

Free, open source, self-hostable. Your terminal, your rules.
