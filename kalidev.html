// what it is

The same platform. Built different.

kalidev is a private variant of Kali Terminal with features that never made it into the public release. Same server, same connection, same shell — but a completely different experience inside the app. It runs as a separate app alongside the public version, with its own package, its own identity, and its own set of tools.

// exclusive features

What's inside.

🟥

Full Red Theme

Every colour in the UI — icon, topbar, cursor, borders, buttons — runs red. Immediately recognisable as something different.

⬛

Matrix Boot Screen

On launch, a full-screen matrix rain animation plays with KALIDEV in red before the app loads. Tap to skip.

📩

Dev Welcome Banner

Every time you connect, a red bordered message prints in the terminal confirming your exclusive access.

⚡

Shortcut Command Bar

A scrollable row of one-tap buttons sits below the topbar — whoami, nmap, ps aux, netstat, top and more. One tap to run.

🛠

Dev Menu

A hidden panel showing your session ID, server address, WebSocket state, live latency, uptime, and command count. Plus force reconnect and session controls.

📡

Shake to Debug

Shake the phone to overlay live debug stats on the terminal — session info, ping, WS state. Shake again to close. Triple-tap the topbar works too.

💾

Saved Servers

Save multiple server URLs and tokens. Switch between them from the connect screen without retyping anything.

🔒

Separate Identity

Package com.kali.terminal.dev — installs and runs alongside the public app without conflicts.
