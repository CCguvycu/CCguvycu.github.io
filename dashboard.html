// the terminal

A real shell. On your phone.

The app connects over a secure WebSocket and renders output through xterm.js — full colour support, interactive programs, window resize. The Linux environment lives entirely on the server, so the phone stores nothing.

// REST API

API-first architecture.

The server never touches the database directly. Everything goes through a FastAPI REST layer with JWT authentication, auto-generated Swagger docs, and paginated endpoints for sessions, commands, and alerts.

Python · FastAPI● live on Railway

    # paginated, filterable, JWT-protected

🔐

JWT Authentication

OAuth2 password flow. Every endpoint validates a signed JWT. Tokens auto-refresh on the client.

📄

Auto Swagger Docs

FastAPI generates live interactive docs at /docs. Every endpoint is documented and testable.

🔗

Internal Endpoints

Private /internal routes let the WebSocket server log sessions, commands, and alerts without DB access.

// admin dashboard

Watch and control every session.

The web dashboard connects to the live API. As admin you can see every session, watch what anyone is typing in real time, and kill a connection instantly — from any browser.

👁

Live View

Click Watch on any active session to open a live terminal mirror inside the browser. Read-only — the user never knows.

■

Kill Sessions

One click to drop a connection. The WebSocket closes server-side, the user's terminal exits instantly.

⚠

Keyword Alerts

Dangerous commands like rm -rf or nc -e trigger instant alerts logged to the database.

🛡

HMAC Cookie Auth

Dashboard login uses HMAC-signed session cookies with 7-day expiry and per-IP rate limiting on login attempts.

📡

IP Logging

Every connection logs the real client IP via X-Forwarded-For, stored per session in PostgreSQL.

🔄

Auto Deploy

GitHub Actions triggers a Railway deploy on every push to master. Zero-downtime continuous deployment.
